# Landing page template — single file, 7 KB

A responsive SaaS/product landing page in **one HTML file**. No build step, no
dependencies, no framework. Rename it, change five CSS variables, ship it.

**[Live preview](https://rez9414.github.io/landing-template/)** — enable GitHub
Pages on this repo (Settings → Pages → Deploy from branch → `main` / root).

## What's inside

- Dark-first design with CSS variables for instant rebranding
- Responsive from 320px to 4K
- Hero, feature grid, pricing, FAQ, footer
- System font stack — zero network requests
- ~7 KB uncompressed

## Use it

```bash
git clone https://github.com/rez9414/landing-template.git
# open index.html in a browser — that's it
```

## Rebrand in 30 seconds

```css
:root {
  --bg: #0b0d12;
  --panel: #141821;
  --text: #e8ecf4;
  --muted: #8b94a7;
  --accent: #6c8cff;   /* change this one first */
}
```
